🌐 HTML 入门学习文档

HTML —— 网页的骨架，带你从零开始构建自己的网页！

一、什么是 HTML？

HTML（HyperText Markup Language，超文本标记语言）是创建网页的标准语言。

  • 它不是编程语言，而是一种标记语言
  • 它用"标签"来描述网页的结构和内容
  • 浏览器读取 HTML 文件，将其渲染成我们看到的网页
可以把 HTML 想象成盖房子的"砖块"——它搭建了网页的基本结构。
而 CSS 是"装修"（美化外观），JavaScript 是"水电"（实现交互功能）。

二、HTML 的基本结构

每个 HTML 文件都有固定的骨架：

<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <title>我的第一个网页</title>
</head>
<body>
    这里写网页的内容
</body>
</html>
标签 说明
<!DOCTYPE html> 文档类型声明，告诉浏览器这是 HTML5 文档
<html> HTML 文档的根元素，所有内容都放在里面
<head> 头部区域，放元数据（标题、编码、样式等）
<body> 主体区域，放所有可见的网页内容

3. 链接

使用 <a> 标签创建超链接：

<a href="https://www.baidu.com">打开百度</a>
<a href="https://www.baidu.com" target="_blank">新窗口打开百度</a>
<a href="#top">回到顶部（锚点链接）</a>
<a href="mailto:example@qq.com">发送邮件</a>

这是一个链接示例

新窗口打开（示例）

属性 说明
href链接的目标地址（必填）
target="_blank"在新标签页中打开
title鼠标悬停时显示的提示文字

4. 图片

使用 <img> 标签插入图片（自闭合标签）：

<img src="图片地址" alt="图片描述" width="300">
属性 说明
src图片路径（必填）
alt图片加载失败时显示的替代文字（必填，有助于无障碍）
width / height设置图片宽高（单位 px）
alt 属性很重要！不仅方便视障用户读屏软件识别，图片加载不出来时也能让用户知道图片内容。

5. 列表

无序列表（用圆点标记）：

<ul>
    <li>苹果</li>
    <li>香蕉</li>
    <li>橙子</li>
</ul>
  • 苹果
  • 香蕉
  • 橙子

有序列表（用数字标记）：

<ol>
    <li>第一步：打开冰箱门</li>
    <li>第二步：把大象放进冰箱</li>
    <li>第三步：关上冰箱门</li>
</ol>
  1. 第一步：打开冰箱门
  2. 第二步：把大象放进冰箱
  3. 第三步：关上冰箱门

7. 表单

表单用于收集用户输入：

<form>
    <label>用户名：</label>
    <input type="text" name="username" placeholder="请输入用户名">

    <label>密码：</label>
    <input type="password" name="password" placeholder="请输入密码">

    <label>性别：</label>
    <input type="radio" name="gender" value="male"> 男
    <input type="radio" name="gender" value="female"> 女

    <label>爱好：</label>
    <input type="checkbox" name="hobby" value="reading"> 阅读
    <input type="checkbox" name="hobby" value="sports"> 运动

    <label>城市：</label>
    <select name="city">
        <option value="beijing">北京</option>
        <option value="shanghai">上海</option>
    </select>

    <textarea rows="4" placeholder="留言内容"></textarea>

    <button type="submit">提交</button>
</form>

input 类型说明
text单行文本
password密码框（输入内容被隐藏）
radio单选框
checkbox复选框
email邮箱（自动校验格式）
number数字
file文件上传
date日期选择器
color颜色选择器

8. 区块与语义化标签

<div>  块级容器（无特殊含义，最常用）</div>
<span> 行内容器（用于包裹一行中的部分文字）</span>

<!-- HTML5 语义化标签 -->
<header>  页面或区块的头部</header>
<nav>     导航栏</nav>
<main>    页面主体内容</main>
<section> 一个独立的区块</section>
<article> 一篇文章或独立内容</article>
<aside>   侧边栏（次要内容）</aside>
<footer>  页面或区块的底部</footer>
语义化标签让代码更容易阅读和维护，也有利于搜索引擎优化（SEO）和屏幕阅读器识别。

四、HTML 注释

注释不会被浏览器显示，用于给开发者做说明：

<!-- 这是注释，不会显示在页面上 -->
<!--
    多行注释
    也是可以的
-->

五、块级元素 vs 行内元素

类型特点常见标签
块级元素 独占一行，宽度默认占满父容器 div p h1~h6 ul ol table form
行内元素 不换行，宽度由内容决定 span a img b i strong em

六、快速入门示例

把下面这段代码复制到记事本，保存为 index.html，用浏览器打开即可看到效果：

<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <title>我的个人主页</title>
</head>
<body>

    <h1>欢迎来到我的个人主页！</h1>

    <p>你好！我是 <strong>小明</strong>，一名前端学习者。</p>

    <h2>我的爱好</h2>
    <ul>
        <li>编程 💻</li>
        <li>阅读 📚</li>
        <li>旅行 ✈️</li>
    </ul>

    <h2>联系我</h2>
    <p>
        📧 邮箱：<a href="mailto:xiaoming@example.com">xiaoming@example.com</a><br>
        🌐 GitHub：<a href="#" target="_blank">github.com/xiaoming</a>
    </p>

    <hr>
    <p>© 2026 小明。保留所有权利。</p>

</body>
</html>
