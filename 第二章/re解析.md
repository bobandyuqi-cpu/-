# 正则表达式常用元字符速查表

## 1. 基础匹配与边界

| 元字符 | 含义 | 示例 |
| :--- | :--- | :--- |
| `.` | 匹配除 `\n` 外的任意单个字符 | `a.c` → abc, a1c |
| `^` | 匹配字符串/行的开头 | `^Hello` → 仅匹配以 Hello 开头的行 |
| `$` | 匹配字符串/行的结尾 | `end$` → 仅匹配以 end 结尾的行 |
| `\b` | 单词边界 | `\bword\b` → 精确匹配 "word" |
| `\B` | 非单词边界 | `\Bword\B` → 匹配嵌入词中的 "word" |

## 2. 量词（重复次数）

| 元字符 | 含义 | 等价写法 |
| :--- | :--- | :--- |
| `*` | 0 次或多次（贪婪） | `{0,}` |
| `+` | 1 次或多次（贪婪） | `{1,}` |
| `?` | 0 次或 1 次 / 量词后加则变懒惰 | `{0,1}` |
| `{n}` | 恰好 n 次 | - |
| `{n,m}` | n 到 m 次（含两端） | - |
| `{n,}` | 至少 n 次 | - |

> ⚠️ **贪婪 vs 懒惰**：量词默认贪婪（尽可能多匹配），后加 `?` 变懒惰（尽可能少匹配）。如 `.*?` 在解析 HTML 时至关重要。

## 3. 字符集 / 预定义字符类

| 元字符 | 含义 | 等价写法 |
| :--- | :--- | :--- |
| `[abc]` | 匹配括号内任一字符 | - |
| `[^abc]` | 匹配不在括号内的字符 | - |
| `[a-z]` | 范围匹配 | `[A-Za-z0-9]` → 字母数字 |
| `\d` | 数字 | `[0-9]` |
| `\D` | 非数字 | `[^0-9]` |
| `\w` | 单词字符（含下划线） | `[A-Za-z0-9_]` |
| `\W` | 非单词字符 | `[^A-Za-z0-9_]` |
| `\s` | 空白字符（空格/制表符/换行等） | - |
| `\S` | 非空白字符 | - |

## 4. 分组与引用

| 元字符 | 含义 | 说明 |
| :--- | :--- | :--- |
| `(pattern)` | 捕获分组 | 可用 `\1` `\2` 引用 |
| `(?:pattern)` | 非捕获分组 | 仅逻辑分组，不占组号，性能更好 |
| `(?P<name>pat)` | 命名分组 | Python 特有，用 `group('name')` 提取 |
| `\|` | 或运算 | `cat\|dog` → 匹配 cat 或 dog |

## 5. 零宽断言（不消耗字符）

| 元字符 | 名称 | 含义 |
| :--- | :--- | :--- |
| `(?=pattern)` | 正向前瞻 | 后面必须是 pattern |
| `(?!pattern)` | 负向前瞻 | 后面不能是 pattern |
| `(?<=pattern)` | 正向后顾 | 前面必须是 pattern |
| `(?<!pattern)` | 负向后顾 | 前面不能是 pattern |

## 📌 高频实战模板

- **验证邮箱**：` +@[\w.-]+\.\w{2,}`
- **提取手机号**：`1[3-9]\d{9}`
- **去除多余空白**：`\s+` → 替换为单个空格
- **匹配中文字符**：`[\u4e00-\u9fff]+`
- **提取标签内容**：`(?<=class="price">)\d+(?=</div>)` （零宽断言典型用例）

> 💡 **转义提醒**：若要匹配 `. * + ? [ ] ( ) { } ^ $ \` 的字面值，必须加 `\` 转义，如 `\.` 匹配点号。建议配合 [regex101.com](https://regex101.com) 在线调试，效率远高于死记硬背。
